# Changelog

## 1.0.8 - 2026-05-05

### Добавлено

- Загрузка в стиле YouTube TV при запуске приложения.
- Индикатор загрузки при открытии канала.
- Категории каналов.
- Навигатор с подсказками по управлению с пульта.
- Встроенные демо-каналы для проверки приложения без входа.
- Отдельный список битых каналов после диагностики.

### Улучшено

- Диагностика теперь проверяет все каналы плейлиста и показывает результат после завершения.
- Нерабочие каналы скрываются из общей ленты, но не удаляются.
- Улучшена стабильность при битых M3U, JSON, EPG и поврежденном кеше.
- Улучшено сохранение последнего состояния и запуск канала после открытия приложения.
- Обновлены скриншоты и описание для RuStore.

### Исправлено

- Приложение не должно падать из-за некорректного плейлиста, EPG или поврежденного кеша.
- Снижены ложные ошибки при запуске каналов.

## 1.0.4

- Опубликованная версия в RuStore.
- Базовый Android TV-плеер с M3U, избранным, EPG и управлением с пульта.
