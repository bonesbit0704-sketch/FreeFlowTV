# FreeFlowTV 1.0.8

## Коротко

Версия 1.0.8 делает приложение заметно удобнее для телевизора: добавлена загрузка в стиле YouTube TV, полноценная диагностика всех каналов, скрытие битых потоков из общей ленты и встроенные демо-каналы для проверки без входа.

## Что нового

- Загрузка в стиле YouTube TV при запуске приложения и открытии каналов.
- Диагностика проверяет все каналы плейлиста и показывает итог после завершения.
- Нерабочие каналы автоматически скрываются из общей ленты.
- Битые каналы не удаляются и доступны через отдельный список.
- Добавлены категории каналов.
- Улучшен навигатор управления с пульта.
- Добавлены встроенные демо-каналы.
- Повышена стабильность при битых M3U, JSON, EPG и поврежденном кеше.

## APK

```text
release/FreeFlowTV-1.0.8.apk
```

## Примечание для модерации

Вход не нужен. Для проверки встроены демо-каналы. Пользователь также может подключить свой M3U. В 1.0.8 улучшены загрузка, диагностика и стабильность.
