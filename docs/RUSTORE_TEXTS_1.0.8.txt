Что нового в 1.0.8 по сравнению с 1.0.4:
Добавлена загрузка в стиле YouTube TV при запуске приложения и открытии каналов.
Диагностика теперь проверяет все каналы плейлиста и показывает итог только после завершения.
Нерабочие каналы автоматически скрываются из общей ленты, но остаются доступными через список битых.
Добавлены категории каналов и быстрый выбор категории с пульта.
Улучшен навигатор по управлению: в приложении есть подсказки для кнопок OK, вверх, вниз, влево, вправо, CH+ и CH-.
Улучшена стабильность при битых M3U, JSON, EPG и поврежденном кеше.
Добавлены встроенные демо-каналы для проверки приложения без входа и без обязательной настройки своего плейлиста.
Улучшено сохранение последнего состояния и запуск каналов после открытия приложения.

Краткое описание:
Легкий IPTV-плеер для Android TV с M3U, EPG, категориями, избранным, диагностикой потоков и демо-каналами.

Полное описание приложения:
FreeFlowTV — приложение для Android TV и Smart TV, созданное для удобного просмотра IPTV-каналов из M3U/M3U8-плейлистов.

Интерфейс адаптирован под телевизор и управление обычным пультом: крупные кнопки, быстрый список каналов поверх видео, переключение CH+/CH-, избранное, категории, экран навигации и понятные подсказки.

После установки приложение можно открыть сразу: внутри есть встроенные демо-каналы для проверки запуска, интерфейса и работы плеера без регистрации и без обязательного ввода своего плейлиста.

Возможности FreeFlowTV:
- импорт пользовательских M3U/M3U8-плейлистов;
- встроенные демо-каналы для проверки приложения;
- избранные каналы;
- категории каналов;
- EPG/телепрограмма, если она есть в источнике;
- быстрый список каналов поверх видео;
- сохранение последнего канала;
- диагностика потоков;
- скрытие нерабочих каналов из общей ленты;
- отдельный список битых каналов;
- загрузочный экран и индикатор запуска канала;
- навигатор с подсказками по управлению с пульта.

FreeFlowTV не требует учетной записи для входа. Пользователь может смотреть демо-каналы или подключить собственный легальный M3U-плейлист.

Комментарий модератору:
Вход не нужен. Для проверки встроены демо-каналы. Пользователь также может подключить свой M3U. В 1.0.8 улучшены загрузка, диагностика и стабильность.
